# Trail Autumn - Development Reasoning

## Concept & Vision
The game name "trail-autumn" immediately suggested an endless runner through a procedurally generated autumn forest. The core fantasy: a solitary wanderer collecting falling leaves on an infinite winding path, surrounded by golden light and drifting particles. Beauty here means atmosphere over mechanics - the feeling of an autumn walk made interactive.

## Technical Architecture

**Single HTML5 Canvas** - No frameworks, no build step, pure vanilla JS. GitHub Pages serves static files; this runs anywhere.

**Three-layer rendering**:
1. Background (sky gradient, fog layers, distant trees at 0.4x parallax)
2. Midground (trail segments, collectible leaves, player, particles)
3. Foreground (near trees at 1x parallax, fireflies)

**Procedural generation** - Trail segments spawn ahead with sine-wave curvature. Each segment carries decorations (rocks, mushrooms, ferns, logs) and leaf spawn points. Trees generate with randomized branching structures and leaf clusters. Everything recycles via object pooling - segments/trees/leaves that scroll past screen bottom get repositioned ahead.

## Game Loop Design
Fixed timestep via `requestAnimationFrame`. Updates in order: trail scroll → player input → leaf collision → combo decay → particles → tree recycling → fireflies → render. Player position lerps toward target for smooth steering; dash is a brief speed multiplier with cooldown.

## Visual Polish
- Autumn palette: 8 leaf colors, 4 trunk tones, 3 ground shades, fog gradients
- Player cloak trails with fade-out ellipses
- Leaf particles burst on collection with physics (gravity, rotation, fade)
- Dash leaves golden streaks
- Fireflies drift with sine-wave horizontal motion
- Screen-space fog gradients for depth
- Combo counter pulses via CSS animation

## Controls
Desktop: Arrow keys / A-D to steer, Space to dash. Mobile: Touch left/right halves to steer, drag for direct positioning. Dash not on mobile (no key) - acceptable tradeoff for simplicity.

## Scope Decisions (YAGNI)
- No enemies, hazards, or fail state - pure collection zen
- No sound - avoids autoplay policy friction
- No settings, pause, or high score persistence
- No level progression beyond speed increase
- Single file per concern (HTML/CSS/JS) - no modules needed

## Performance
~60fps on mobile. Particle count capped by decay. Tree count fixed (20 foreground, 30 background). Trail segments ~20. All math is simple arithmetic - no allocations in hot path except particle spawn.

## Files
- `index.html` - Canvas + UI screens
- `style.css` - Autumn-themed UI, responsive
- `game.js` - Entire game logic (~450 lines)
